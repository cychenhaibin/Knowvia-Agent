# FluxA 登录页布局与站点名称

## 目标

简化 FluxA 登录页的账号输入区域，并使公益站名称清晰一致。

## 范围

- 移除账号与密码输入框外层的圆角浅色容器。
- 两个输入框在 FluxA 页面均占据可用全宽；未选择站点时仍通过透明度置灰。
- 将简体中文 `login.fluxaSite.free` 改为 `FluxA 公益站`。
- 不改路由、站点值（`free`）、登录请求或会话流程。

## 验证

- 对简体中文翻译添加回归断言。
- 对登录页源码添加布局回归断言，确保输入区没有圆角容器且两个输入字段使用全宽容器。
- 运行完整客户端测试，并在已连接 Android 设备重新加载调试包。
